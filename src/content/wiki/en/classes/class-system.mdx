## How does the Emberville class system work?

Emberville uses changeable combat classes rather than a permanent class choice at character creation. The official Steam description says players can choose from multiple classes, change class at any time, and build a fighting style using active and passive skills inherited from other learned classes. That makes class progression part of long-term build experimentation instead of a one-time decision.

The official material does not yet define every restriction on swapping, inheritance, loadouts, or resetting progression. Treat specific limits shown in the Steam Next Fest demo as a snapshot, not a promise for Early Access. Start with the [beginner guide](/guides/beginner-guide/) before using the [skills directory](/skills/) to compare the known demo abilities.

## Can you switch classes on one character?

Yes. Cygnus Cross describes classes as choices that can be changed at any time, so players should not need a new character merely to try a different combat role. The exact location, cost, and conditions for switching are not fully documented in the official public material and remain **[待补充]**.

This flexibility matters because weapons also have their own combos. A class supplies abilities and progression, while the equipped weapon affects the attacks available during combat. The [combat and inheritance guide](/mechanics/combat-and-skill-inheritance/) explains how those layers relate without assuming unconfirmed numerical formulas.

## What does skill inheritance mean?

The official Steam page says a combat class can inherit passive and active skills from other classes the character has learned. In practical terms, the intended system supports hybrid builds rather than requiring every character to remain inside one class kit. However, public official sources do not yet confirm how many inherited skills fit in a build or whether every skill is eligible.

Avoid treating a demo skill tree as the final inheritance interface. Demo-observed abilities in the [Emberville skills database](/skills/) are labeled by evidence status, and uncertain names are marked `待复核`. Build rankings should wait until the launch build exposes stable values and restrictions.

## How should a new player choose a class?

Choose based on the combat behavior you want to learn first, not an unofficial tier list. The demo snapshot presents Knight as a close-range defensive fighter, Mage as a Kymia-focused ranged caster, and Wanderer as a mobile utility class. Archer has been referenced in pre-release material but was not playable in the verified demo snapshot, so its final behavior is still pending.

New players can compare these roles in the [demo classes overview](/classes/demo-classes/), then review the [gameplay guide](/guides/gameplay/) for the broader loop of combat, gathering, rebuilding, and exploration. The site will add verified class recommendations only after stable release data is available.

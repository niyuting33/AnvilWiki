## Which Emberville classes were playable in the demo?

Knight, Mage, and Wanderer were the three playable class identities observed in the Steam Next Fest demo snapshot used by this wiki. Archer was referenced but not playable in the same verified snapshot. This is not a final launch roster, and it should not be read as confirmation that Early Access contains only these classes.

<Callout type="warn" title="Demo snapshot, not a final roster">
Class names and broad roles were observed before Early Access. Exact stats, unlock order, skill counts, and balance are deliberately omitted until they can be independently verified in a stable build.
</Callout>

## What is the Knight class for?

Knight is the clearest close-range defensive option in the demo snapshot. Its observed ability themes include blocking, counterattacks, knockback, stuns, pursuit, and survival under pressure. This suggests a deliberate style that rewards timing and control rather than simply absorbing every attack.

Players interested in Knight can filter the [skills directory](/skills/) by class and active/passive type. Numeric damage, Kymia, cooldown, and rank values are not reproduced because they may be build-specific or outdated. The [class-system guide](/classes/class-system/) explains how a learned class may contribute skills to a wider build.

## What is the Mage class for?

Mage centers on ranged Kymia attacks, area pressure, resource recovery, and summoned support. Demo-observed skill themes include projectiles, a charged beam, a damaging trail, a Soul Wisp, and ways to recover or expand Kymia. The official Steam page independently confirms that Emberville includes magic combat and an equipment-and-skills system, but it does not confirm each demo value.

Mage therefore looks suited to players who prefer spacing and resource management. Whether its final Early Access version keeps the same ability names, progression branches, or balance is **[待补充]**. Review [Kymia and rebuilding mechanics](/mechanics/kymia-crafting-and-town-rebuilding/) for the verified role of Kymia in the setting and gameplay loop.

## What is the Wanderer class for?

Wanderer appears to be a mobile utility class with recovery, exploration, and gathering support. Its observed themes include dash improvements, movement speed, healing, Kymia recovery, hazard resistance, and material-gathering utility. That breadth makes it useful for understanding how non-damage tools can support the larger exploration loop.

The exact strength of these effects is not published here. Demo values cannot safely support a class ranking before Early Access balance stabilizes. For the broader opening flow, read the [beginner guide](/guides/beginner-guide/) and [tips guide](/guides/tips/).

## Is Archer confirmed as playable?

Archer is a pre-release class reference associated with ranged control and poison, but it was not playable in the verified demo snapshot used for this page. Its final abilities, attributes, unlock method, and Early Access availability are all **[待补充]**. The site will not invent an Archer skill tree to fill that gap.

## Which class is best?

There is not enough stable evidence for a trustworthy best-class ranking. A valid comparison needs the release build, actual encounter conditions, inheritance restrictions, gear interactions, and repeatable tests. Until those exist, choose Knight for close defensive control, Mage for ranged Kymia play, or Wanderer for mobility and utility—then treat every recommendation as provisional.

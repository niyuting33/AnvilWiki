## Why is Wanderer not placed in S tier?

Being the only confirmed playable class does not make Wanderer the strongest class. A tier placement requires at least one meaningful comparison against another available class using the same version, encounter, equipment assumptions, and evaluation criteria. Without that comparison, an S-tier label would measure availability rather than strength.

The collected material describes Wanderer as a mobile, adaptive class focused on survival. That description helps explain its intended play style, but it does not establish damage rankings, endgame value, or superiority over classes that cannot yet be tested. Read the [class and combat overview](/guides/gameplay/) for the confirmed separation between class progression and weapon mastery.

## What would make a future ranking publishable?

A future tier list needs comparable tests, not only names seen in menus. Each candidate should be available in the same build, tested against the same goal, and described with one concise reason that can be reproduced. If a result depends strongly on a boss, mastery level, equipment roll, or control scheme, it should be labelled as a situational ranking rather than a universal tier.
